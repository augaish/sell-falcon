# سيل فالكون — مساعد مبيعات وشراكات شخصي (المرحلة 0)

نسخة تجريبية محلية. لا ترسل رسائل، لا تتصل بخدمات خارجية، ولا تنفق شيئًا.

## التشغيل

```bash
python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
python manage.py init you@example.com      # يطبع كلمة مرور المالك
python manage.py seed-demo                 # اختياري: بيانات مختلقة موسومة «تجريبي»
uvicorn app:app --host 127.0.0.1 --port 8765
```

## الاختبار

```bash
pip install pytest httpx && pytest tests          # الخلفية
node tests/mobile.e2e.js screenshots              # الواجهة على الجوال وسطح المكتب (الخادم يعمل ببيانات seed-demo وحساب demo@sellfalcon.test)
```

## ما يضمنه الكود

- **عزل المشاريع:** ملف SQLite لكل مشروع في `data/projects/`. `core.db` يحمل الحسابات، قائمة عدم التواصل، فهرس منع التكرار (مفاتيح فقط) وسجل النشاط.
- **التكلفة لكل مشروع:** جدول `costs` داخل قاعدة كل مشروع، يفصل الفعلي عن التقديري، وحد شهري يوقف الإجراءات المدفوعة (`guard_spend`).
- **بوابة التواصل (`send_blockers`):** تسجيل الإرسال يتطلب فرصة معتمدة، مسودة معتمدة بمحتواها ومستلمها الحاليين، أساس تواصل موثق، تأكيد مراجعة شروط المصدر، مراجعة نظامية لدولة المستلم، وعدم وجوده في قائمة عدم التواصل.
- **لا بيانات بلا مصدر:** جهة التواصل لا تُقبل بلا رابط مصدر، والمصدر بلا تاريخ يظهر «غير متحقق منه».
- **النسخ الاحتياطي:** `python manage.py backup x.tar.gz` ثم `restore x.tar.gz NEW_DIR` (يتحقق من سلامة كل ملف).

## مكوّنات المرحلة 1 (مجانية، مغلقة خلف بوابات)

- `spend.py`: حجز أسوأ احتمال، حد شهري ويومي لكل مشروع، تكلفة «غير محسومة» عند انقطاع الطلب، إيقاف تلقائي ويدوي. المزوّد الوحيد وهمي.
- `discovery.py`: قارئ مواقع (robots.txt، طلب في الثانية، الصفحة الرئيسية فقط حتى تُراجَع شروط الموقع، عناوين عامة فقط)، استيراد OpenStreetMap في جدول مستقل للقراءة فقط، واستخراج ومسودات عبر النموذج.
- البوابات في «الإعداد»: تقييم نظامية البيانات، ورخصة OSM. مغلقة افتراضيًا.

لم يُجرَّب شيء من هذا على شبكة أو مزوّد حقيقي. الخطة والحالة التفصيلية في `docs/PHASE1-SA.md`.

## غير موجود بعد
